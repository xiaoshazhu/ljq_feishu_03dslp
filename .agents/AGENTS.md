# Agents Rules

## 通用规则 (General Rules)
- **称呼**: 必须称呼用户为“小廖”。
- **语言**: 必须使用中文回答所有问题。
- **代码变动限制**: 请勿改动项目中的源代码（.js, .ts, .vue 等逻辑代码），仅允许通过修改配置文件（如 `.env`, `.env.staging`, `.env.production` 等）来启动和调试代码。
- **配置调试重点**: 针对 ngrok 隧道配置、数据库连接、IP 绑定等环境配置进行必要的排查与调整。
- **开发与部署依据**: 遵循项目根目录下 [README.md](file:///d:/%E9%AB%98%E5%8E%9F%E5%AE%89/%E4%BB%A3%E7%A0%81/doudianfeishu/README.md) 中关于本地开发、生产构建、线上测试与环境验证的规范。
